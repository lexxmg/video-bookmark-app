# 🎬 Video Study App

Удобное веб-приложение для детального изучения видеоматериалов (лекций, уроков, подкастов) по фрагментам. Позволяет расставлять именованные метки-таймкоды, мгновенно перемещаться к нужным моментам, управлять плеером с клавиатуры и централизованно хранить настройки.

Проект полностью автономен, работает внутри **Docker** и не требует установки PHP, баз данных или Node.js на локальный компьютер.

---

## ✨ Ключевые возможности

*   **Каталог видео с автопревью:** На главной странице выводятся плитки видеоматериалов. Кадры-миниатюры автоматически генерируются из самого видео и кэшируются в отдельную папку.
*   **Умные метки (Таймкоды):** Возможность добавлять фрагменты с названиями прямо во время просмотра. Метки автоматически сортируются по времени видеоролика (от начала к концу).
*   **Управление без мыши:** Клавиша `Пробел` ставит видео на паузу или запускает его (автоматически отключается, если вы вводите текст в форме).
*   **Запоминание громкости:** Уровень звука сохраняется для каждого видео индивидуально прямо в базу данных SQLite. При перезагрузке страницы звук останется на прежнем уровне.
*   **Полноценная админка:** Загрузка тяжелых файлов (до 2 ГБ) и полное удаление роликов вместе с их файлами и метками прямо из браузера.
*   **Защита от сбоев:** Автоматическая синхронизация базы данных и диска — при случайном удалении превью руками система сама пересоздаст его на лету.

## 🚀 Быстрый запуск на локальной машине или сервере

Проект оптимизирован для работы по принципу **«скачал и запустил одной командой»**.

### Шаг 1. Установка Docker (если еще не установлен)

#### Для локального компьютера (Windows / macOS):
Скачайте и установите графическое приложение [Docker Desktop](https://docker.com). Убедитесь, что оно запущено.

#### Для удаленного Linux-сервера (Ubuntu/Debian):
Подключитесь к серверу по SSH и выполните официальный скрипт установки:
```bash
curl -fsSL https://docker.com -o get-docker.sh
sudo sh get-docker.sh
```

### Шаг 2. Развертывание проекта

1. Склонируйте репозиторий с GitHub или скачайте архив с кодом на сервер:
   ```bash
   git clone https://github.com
   cd video-study-app
   ```
2. Запустите Docker-контейнеры одной командой:
   ```bash
   docker compose up -d --build
   ```

Приложение автоматически соберется и станет доступно по адресу: **`http://localhost:8080`** (или по IP-адресу вашего сервера).

## 🛠️ Руководство пользователя

### 1. Как добавлять новые видеоматериалы
*   **Способ А (Рекомендуемый, через интерфейс):** Перейдите во вкладку **«⚙️ Админка»** в шапке сайта. В блоке «Загрузить новое видео» выберите файл в формате `.mp4` и нажмите кнопку отправки. Система загрузит его (поддерживаются файлы до 2 ГБ) и сама внесет в базу.
*   **Способ Б (Локальный ручной):** Вы можете просто перенести ваш `.mp4` файл напрямую в папку `storage/videos/` на жестком диске. После этого зайдите в «Админку» и нажмите синюю кнопку **«🔄 Синхронизировать файлы на диске»**.

### 2. Изучение материала и расстановка меток
*   Откройте плитку нужного видео на Главной странице.
*   Во время просмотра нажмите `Пробел` для паузы на важном моменте.
*   Нажмите синюю кнопку **«+ Поставить метку»** в правой колонке.
*   Введите название фрагмента и нажмите «Сохранить». Видео автоматически снимется с паузы, а метка встанет на свое место в списке.
*   Клик по любой созданной метке мгновенно перематывает плеер на этот фрагмент.

### 3. Удаление и очистка хранилища
*   Если видеоматериал больше не нужен, перейдите в **«⚙️ Админка»**.
*   В нижней таблице найдите нужный ролик и нажмите красную кнопку **«🗑️ Удалить»**.
*   Сервер полностью сотрет видеофайл `.mp4`, удалит картинку-превью из папки `thumbnails`, а база данных за счет каскадного удаления (`ON DELETE CASCADE`) мгновенно очистится от всех закладок, принадлежавших этому видео.

## 📂 Структура каталогов проекта

```text
video-learning-app/
├── docker-compose.yml     # Конфигурация сервисов Docker (PHP-FPM, Nginx)
├── Dockerfile             # Инструкция сборки PHP-окружения с PDO SQLite
├── nginx.conf             # Настройки веб-сервера (маршруты, раздача медиа и лимиты)
├── .gitignore             # Защита от попадания личных видео и баз данных в Git
│
├── database/
│   └── database.sqlite    # Постоянный файл БД на хосте (работает в режиме WAL)
│
├── public/                # Доступный извне каталог сайта
│   ├── index.php          # Главная страница (сетка плиток с ленивой генерацией превью)
│   ├── watch.php          # Страница плеера (управление пробелом, громкостью и AJAX-метками)
│   ├── admin.php          # Панель управления (загрузка файлов до 2ГБ, синхронизация и удаление)
│   ├── api.php            # Единый бэкенд-обработчик всех AJAX/POST запросов
│   └── includes/
│       ├── db.php         # Логика подключения к PDO и инициализации таблиц
│       ├── header.php     # Общая шапка и навигация сайта
│       ├── footer.php     # Общий подвал страниц
│       └── tailwind.css   # Автономный локальный файл стилей Tailwind v2
│
└── storage/               # Локальное постоянное хранилище медиафайлов
    ├── videos/            # Папка для хранения видеофайлов .mp4
    └── thumbnails/        # Папка для автоматически генерируемых кадров .jpg
```

## 🔒 Безопасность при работе с Git (Важно)

В файле настроек `.gitignore` уже прописаны правила исключения. При отправке проекта на GitHub ваши личные видеофайлы из папки `storage/` и текущая база данных `database.sqlite` **не попадут в публичный доступ**. Репозиторий всегда будет оставаться легким и чистым, готовым к развертыванию с нуля.
