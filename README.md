# 🎬 Video Study App

Современное и полностью автономное веб-приложение для детального изучения видеоматериалов (лекций, уроков, подкастов) по фрагментам. Позволяет расставлять именованные метки-таймкоды, мгновенно перемещаться к нужным моментам видео, управлять плеером с клавиатуры и сохранять индивидуальные настройки.

Проект разработан на базе **Docker** по стандарту «микросервисов» продакшн-уровня. Сборка стилей полностью автоматизирована через встроенный **Node.js** и **Tailwind v4 CLI**, обеспечивая кроссплатформенность и высочайшую скорость работы как на компьютерах Intel/AMD, так и на Apple Silicon (M1/M2/M3/M4).

---

## ✨ Ключевые возможности

*   **Умный каталог с автопревью:** На главной странице отображается сетка плиток. Видео-миниатюры автоматически вырезаются из файлов при первой загрузке методом «ленивой очереди» (нагрузка на процессор равна нулю) и кэшируются в отдельный каталог.
*   **Интерактивные метки (Таймкоды):** Добавление именованных фрагментов прямо во время просмотра. База данных SQLite автоматически сортирует метки по времени ролика (от начала к концу). Клик по метке мгновенно перематывает плеер на нужную секунду.
*   **Управление без мыши (UX):** Клавиша `Пробел` ставит видео на паузу или запускает его. Фокус автоматически отключается, если вы вводите текст в форме, чтобы не мешать набору пробелов.
*   **Индивидуальная громкость:** Уровень звука сохраняется для каждого видео индивидуально прямо в базу данных. При перезагрузке страницы или смене видео ползунок останется ровно там, где вы его оставили.
*   **Полноценная админка (SaaS-ready):** Поддерживает загрузку тяжелых видеофайлов (до 2 ГБ) с индикацией отправки, ручную синхронизацию и полное безопасное удаление медиафайлов и картинок с диска одной кнопкой.
*   **Защита от сбоев («Защита от дурака»):** Если файл превью `.jpg` был случайно удален из папки руками, система на лету обнаружит это при открытии главной страницы, сбросит флаг в БД и автоматически пересоздаст миниатюру.

## 🚀 Быстрый запуск (Локально или на Сервере)

Проект оптимизирован для развертывания **ровно одной командой** и не требует наличия Node.js, PHP или баз данных на хост-машине.

### Шаг 1. Установка Docker (если еще не установлен)

*   **Для локального компьютера (Windows / macOS на Intel или Apple Silicon M1/M2/M3/M4):**
    Скачайте и установите графическое приложение [Docker Desktop](https://docker.com). Убедитесь, что оно запущено.
*   **Для удаленного Linux-сервера (Ubuntu/Debian):**
    Подключитесь к серверу по SSH и выполните официальный скрипт установки:
    ```bash
    curl -fsSL https://docker.com -o get-docker.sh
    sudo sh get-docker.sh
    ```

### Шаг 2. Развертывание проекта

1. Склонируйте репозиторий с кодом на машину или сервер и перейдите в папку:
   ```bash
   git clone https://github.com
   cd video-bookmark-app
   ```

2. **ПЕРВЫЙ ЗАПУСК (Сборка проекта):** Запустите компиляцию стилей Tailwind v4 и сборку окружения одной командой (выполняется **только один раз** при установке):
   ```bash
   docker-compose up -d --build
   ```

3. **ПОСЛЕДУЮЩИЕ ЗАПУСКИ:** Для повседневного использования пересборка не требуется. Проект включается мгновенно за 1 секунду обычной командой:
   ```bash
   docker-compose up -d
   ```

4. **ОСТАНОВКА ПРОЕКТА:** Чтобы временно выключить приложение и освободить оперативную память компьютера, выполните:
   ```bash
   docker-compose down
   ```


Приложение автоматически скомпилирует стили Tailwind v4 под архитектуру вашего процессора и станет доступно по адресу: **`http://localhost:8080`** (или по IP-адресу вашего сервера).

## 🛠️ Инструкция по управлению файлами

### 1. Как добавлять новые видеоматериалы
*   **Через браузер:** Перейдите во вкладку **«⚙️ Админка»** в шапке сайта. В блоке «Загрузить новое видео» кликните по удобной интерактивной зоне выбора, выберите файл в формате `.mp4` и нажмите «Начать загрузку». Система загрузит файл (до 2 ГБ) и сама внесет его в базу.
*   **Ручной перенос:** Вы можете просто перенести ваш `.mp4` файл напрямую в папку `storage/videos/` на жестком диске. После этого зайдите в «Админку» и нажмите синюю кнопку **«🔄 Синхронизировать файлы на диске»**.

### 2. Как удалять файлы и очищать место
*   Перейдите в **«⚙️ Админка»**.
*   В нижней таблице найдите нужный ролик и нажмите красную кнопку **«🗑️ Удалить всё»**.
*   Сервер полностью сотрет видеофайл `.mp4`, удалит картинку-превью из папки `thumbnails`, а база данных за счет каскадного удаления (`ON DELETE CASCADE`) мгновенно очистится от всех закладок таймкодов, принадлежавших этому видео. Память вашего ПК останется чистой.

## 📂 Структура каталогов проекта

```text
video-bookmark-app/
├── docker-compose.yml     # Конфигурация сервисов Docker (PHP-FPM, Nginx, Node.js-сборщик)
├── Dockerfile             # Инструкция сборки PHP-окружения с поддержкой Node.js и PDO SQLite
├── nginx.conf             # Настройки веб-сервера (маршруты, раздача медиа и лимиты загрузки 2ГБ)
├── .gitignore             # Защита от попадания личных видео, картинок и баз данных в Git
│
├── database/
│   └── database.sqlite    # Файл постоянного хранения БД на хосте (работает в режиме PRAGMA WAL)
│
├── public/                # Публичный каталог сайта, доступный из веб
│   ├── index.php          # Главная страница (сетка плиток Tailwind v4 с ленивой генерацией превью)
│   ├── watch.php          # Страница плеера (управление пробелом, громкостью и AJAX-метками)
│   ├── admin.php          # Панель управления (загрузка файлов, drag-and-drop зона и удаление)
│   ├── api.php            # Единый бэкенд-обработчик всех AJAX/POST запросов фронтенда
│   └── includes/
│       ├── db.php         # Логика подключения к PDO SQLite и инициализации таблиц
│       ├── header.php     # Общая шапка и навигация сайта
│       ├── footer.php     # Общий подвал страниц
│       ├── input.css      # Исходный файл стилей с правилом сканирования @source
│       └── tailwind.css   # Скомпилированный продакшн-файл стилей Tailwind v4 (генерируется Docker)
│
└── storage/               # Локальное постоянное хранилище медиафайлов
    ├── videos/            # Папка для хранения видеофайлов .mp4
    └── thumbnails/        # Папка для автоматически генерируемых кадров-миниатюр .jpg
```

## 🔒 Важно для безопасности Git

В файле настроек `.gitignore` уже жестко прописаны правила исключения. Ваши личные тяжелые видеофайлы из папки `storage/videos/`, картинки из `storage/thumbnails/` и рабочая база данных `database.sqlite` **никогда не попадут на GitHub**. Репозиторий всегда будет оставаться легким, чистым и безопасным для публикации в открытом доступе.
