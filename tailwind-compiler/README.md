# 🛠️ Памятка разработчика: Сборщик стилей Tailwind v4

Этот изолированный контейнер на базе Node.js предназначен для сборки стилей проекта. Он полностью отрезан от основного сайта, спит во время обычной работы и запускается **строго вручную**, когда вам нужно обновить интерфейс.

---

## 🚀 Основные команды управления

### 1. Сборка самого компилятора (Выполняется 1 раз)
Если вы только что скачали проект с GitHub или изменили конфигурацию в `tailwind-compiler/Dockerfile`, соберите образ компилятора:
```bash
docker-compose build builder
```

### 2. Принудительная компиляция стилей (Выполняется по необходимости)
Запустить сканирование проекта и сгенерировать свежий CSS-файл прямо на ваш компьютер:
```bash
docker-compose run --rm builder
```
*   **Для чего это делается:** Контейнер Node.js на 2 секунды включится, прочитает ваш файл `input.css`, по правилу `@source` просканирует все файлы `.php` в проекте, найдет новые классы Tailwind, запишет легкий, сжатый файл `public/includes/tailwind.css` (около 19 КБ) на ваш жесткий диск и **автоматически удалится из оперативной памяти вашего компьютера** благодаря флагу `--rm`.

---

## 💡 Когда нужно запускать компилятор?

1.  **При первом развертывании проекта** на новом компьютере или сервере (чтобы сгенерировать CSS-файл с нуля).
2.  **Если вы добавили новый класс** в верстку (например, поменяли цвет кнопки с `bg-blue-600` на `bg-red-600` или добавили новые отступы).
3.  **Если вы создали новый PHP-файл** с уникальной версткой, стили которой еще не зашиты в текущий CSS.

---

## 💤 Повседневная работа (Компилятор отдыхает)
Для обычного ежедневного использования компилятор запускать **не нужно**. Сайт включается стандартной командой:
```bash
docker-compose up -d
```
Docker запустит только чистый PHP-FPM и Nginx, которые будут мгновенно отдавать уже готовый скомпилированный файл `tailwind.css` с вашего диска.
